# Avatar Prompts

Player avatars for the intro lobby: `sql-front/public/avatars/avatar-NN.png`. Default is `(id - 1) % 60 + 1`; players can pick another one during `init`.
Until an image exists, the lobby shows the player's initial instead.

The avatars are shared by all editions, so they carry no edition colors.
The edition theme comes from the CSS around them: `.df-avatar` crops to a circle and sets the background and border.

- Generate #01 first, then append `--sref <url-of-01>` to the rest to keep a consistent style
- Remove the white background (e.g. `rembg p ./raw ./avatars`) to get transparent PNGs
- Save as square transparent PNG, ~256x256: `avatar-01.png` ... `avatar-60.png`
- `AVATAR_COUNT` in `sql-front/src/game.ts` must match the number of images

Shared style suffix (already included below):

```
, centered head-and-shoulders character portrait with generous empty margin, bold flat vector illustration, thick dark outlines, limited palette of 4-5 saturated colors, plain solid white background --no text, frame, border, circle, shadow, gradient --ar 1:1 --v 7 --style raw
```
