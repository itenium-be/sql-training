# Avatar Prompts

Player avatars for the intro lobby: `sql-front/public/avatars/avatar-NN.png`. Default is `(id - 1) % 60 + 1`; players can pick another one during `init`.
Until an image exists, the lobby shows the player's initial instead.

The avatars are shared by all editions: the dark espresso background is neutral enough for any theme, only the ring around them (`.df-avatar` in the CSS) follows the edition.

- No `--sref`: the shared suffix keeps the set consistent without cloning one character. If one drifts, regenerate it with `--sref <url> --sw 50`
- Save as square PNG, ~256x256: `avatar-01.png` ... `avatar-60.png`
- `AVATAR_COUNT` in `sql-front/src/game.ts` must match the number of images

Shared style suffix (already included below):

```
, circular badge avatar, waist-up character portrait clearly showing their SQL-themed prop, bold flat vector illustration, thick clean outlines, warm palette of gold #e9b44c, copper #c47a35 and cream on a dark espresso brown background, subtle glow --no text --ar 1:1 --v 7 --style raw
```
