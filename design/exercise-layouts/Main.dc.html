Exercise 3

2 points

For South America show population in millions and GDP in billions, both to 2 decimal places. Sort them by largest GDP.

Expected columns
name population (M) gdp (B)
13 rows · order matters
Hint

Using COUNT(a), COUNT(b) will have "b" overwrite the values of "a". Use aliases!

SELECT name,
       ROUND(population / 1000000.0, 2) AS "population (M)",
       ROUND(gpd / 1000000000.0, 2) AS "gdp (B)"
FROM countries
WHERE continent = 'South America'
ORDER BY gdp DESC
column "gpd" does not exist
